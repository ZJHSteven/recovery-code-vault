RECOVERY VAULT / AGE V1

加密恢复金库

恢复资料始终以 age 标准加密文件存放。这个页面只提供本地浏览器解密功能，服务器不持有你的解密密钥。

1. 选择密文来源

默认读取当前站点托管的 vault.age。即使 GitHub 或 Cloudflare 不可用，也可以从 iCloud、U 盘或其他备份位置选择你保存的副本。

尚未选择本地文件，将使用当前站点的密文

2. 输入独立保存的身份密钥

在 Apple 密码、可信离线介质或受保护的恢复渠道找到 AGE-SECRET-KEY-…。Passkey 认证本身不等于解密密钥，不能凭登录本网站直接获取明文。

安全与恢复说明

本页面无分析脚本、无第三方字体或 CDN、无服务端上传接口。浏览器只对当前站点发出读取静态加密文件的请求。解密后的 ZIP 中含敏感恢复资料，请勿将其分享到公开网站。

同一份密文可复制到不同托管位置，但仅重复复制密文不能代替独立保存解密密钥。请同时保留跨设备有效的身份密钥和离机备份。

使用标准 age 文件格式；应用代码可独立保存，恢复不依赖本站持续在线。
